# H_C Scheduling Manager

**Stand: 1.1.0-test – private Release-Vorbereitung, kein öffentlicher Download**

Ein Windows-Desktop-Tool zum Verwalten einmaliger und wiederkehrender Wartungsaufgaben.

## Funktionen
- Aufgaben erstellen, bearbeiten, anzeigen und als erledigt markieren
- Wiederholungen in Tagen, Wochen, Monaten oder Jahren
- Serienbearbeitung: nur ein Termin, ab einem Termin oder gesamte Serie
- Bereits erledigte Termine bei Neuplanung erhalten
- Benutzerkonten mit Freigabe und Rollen
- Zeitfilter und Excel-Export

## Noch nicht enthalten
Materialverwaltung, automatische Backups, automatische Updates, Netzwerksynchronisierung und fertiger Windows-Installer.
