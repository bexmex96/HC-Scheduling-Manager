# Checkliste vor einem öffentlichen GitHub-Release

- [ ] Verwertungsrechte am eigenen Code und verwendeten Ressourcen geklärt
- [ ] Lizenztext endgültig festgelegt, notwendige Angaben ergänzt
- [ ] Windows-GUI mit Erstadmin, Registrierung, Freigabe und Rollen getestet
- [ ] Intervalle Tage/Wochen/Monate/Jahre einschließlich Schaltjahr und Monatsende geprüft
- [ ] Einzeltermin, zukünftige Termine und gesamte Serie getestet
- [ ] Erledigte Termine bleiben erhalten
- [ ] Unberechtigte Änderungen zwischen Benutzerkonten verhindert
- [ ] Löschen, Excel-Export und Dokumentverknüpfungen getestet
- [ ] Datenbank-Backup und Wiederherstellung getestet
- [ ] Windows-EXE/Installer erstellt und auf sauberem Rechner ohne Python getestet
- [ ] Paket auf personenbezogene Daten, Secrets und fremde Inhalte geprüft
- [ ] Installationsanleitung, Lizenz und SHA-256-Prüfsumme ergänzt
- [ ] Erst danach öffentlichen Pre-release erstellen
